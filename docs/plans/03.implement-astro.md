### Objective:
To migrate the existing static HTML and Markdown content into a new Astro project. This will provide a more robust, performant, and maintainable solution for the course website, leveraging Astro's strengths for content-heavy sites.

### Key Technologies:
*   **Astro:** A modern static site generator.
*   **Tailwind CSS:** For utility-first styling, integrated via Astro's official integration.

### Implementation Steps:

1.  **Initialize Astro Project:**
    *   Run `npm create astro@latest` in the project root.
    *   When prompted, choose the "Empty" starter project for a clean slate.
    *   This will create a new directory structure. We will need to move the existing project files into this new structure.

2.  **Integrate Tailwind CSS:**
    *   Run `npx astro add tailwind` within the new Astro project directory.
    *   This command will handle the installation and configuration of Tailwind CSS.

3.  **Create Layouts and Components:**
    *   Create a main `Layout.astro` in `src/layouts/`. This file will contain the common HTML boilerplate (the `<head>`, header, and footer) from the original design.
    *   Re-create the header and footer as Astro components in `src/components/`.

4.  **Migrate Content:**
    *   Move the `course_expanded.md` file to `src/content/course/course.md`.
    *   Create a dynamic page at `src/pages/weeks/[week].astro`. This page will be responsible for generating the weekly pages.
    *   The logic in this dynamic page will:
        *   Read the `course_expanded.md` file.
        *   Parse the content and group it by week.
        *   Generate the HTML for the accordion component for the daily content.

5.  **Update Index Page:**
    *   Update `src/pages/index.astro` to be the main landing page, using the styles and content from the original `index.html`.
    *   This page will link to the 5 weekly pages (e.g., `/weeks/1`, `/weeks/2`, etc.).

6.  **Cleanup:**
    *   Once the Astro site is functional, we will remove the original `src/` directory with the static HTML files.

### Testing Strategy:
1.  **Development Server:** Use `npm run dev` to start the Astro development server and get live previews of the site.
2.  **Visual Verification:** Open the site in a browser and verify that all pages render correctly and that the styling is consistent with the design system.
3.  **Functionality Testing:** Test the accordion functionality on the weekly pages to ensure that the daily content expands and collapses correctly.
4.  **Content Verification:** Spot-check the content on the weekly pages to ensure that it matches the `course_expanded.md` file.
