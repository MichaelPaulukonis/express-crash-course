### Problem Statement:
The `src/` directory contains static HTML files that are not practical for displaying the 33-day course content from `docs/course_expanded.md`. A single page for all content is too long, and a page for each day is too fragmented. The current `src/` files do not reflect the comprehensive content, leading to a discrepancy between the documentation and the presented course material.

### Requirements:
1.  Restructure the course content into a weekly format, with 5 weeks in total.
2.  Each week will have its own HTML page.
3.  The daily content within each week will be displayed in an accordion-style interface to keep the page clean and organized.
4.  The `index.html` file will be updated to link to the 5 new weekly pages.
5.  The content from `docs/course_expanded.md` must be accurately converted from Markdown to HTML.

### Technical Approach:
1.  **Content Extraction and Conversion:**
    *   Read `docs/course_expanded.md`.
    *   Parse the Markdown content to extract each day's details.
    *   Group the 33 days of content into 5 weeks.
    *   Implement a robust Markdown-to-HTML conversion function.
2.  **HTML Template Generation:**
    *   Extract the common HTML boilerplate from `src/page_02.html`.
    *   Create a template for the weekly pages that includes an accordion component.
3.  **File Management:**
    *   Generate 5 new HTML files: `week-1.html`, `week-2.html`, `week-3.html`, `week-4.html`, and `week-5.html`.
    *   Update `src/index.html` to link to the new weekly pages.
    *   Remove the old `src/page_02.html` and `src/page_03.html` files.

### Implementation Steps:
1.  **Update `02.update-course-content.md` in `docs/plans/`** with this detailed plan.
2.  **Read `docs/course_expanded.md`**: Get the full content of the expanded course.
3.  **Read `src/page_02.html`**: Extract the common HTML boilerplate.
4.  **Parse `docs/course_expanded.md`**: Develop a script to parse the Markdown and group the content into 5 weeks.
5.  **Implement Markdown to HTML Converter**: Create a function to convert the extracted Markdown content into appropriate HTML.
6.  **Generate Weekly HTML Files**:
    *   Loop through the 5 weeks of content.
    *   For each week, construct the full HTML page, including the accordion component for the daily content.
    *   Write the generated HTML to a new file in `src/` named `week-X.html`.
7.  **Add Accordion JavaScript**: Add a small script to the weekly pages to handle the accordion functionality (opening and closing the daily content).
8.  **Update `src/index.html`**:
    *   Change the course duration from "30-Day" to "33-Day".
    *   Add a section with links to the 5 weekly pages.
9.  **Clean up old files**: Remove `src/page_02.html` and `src/page_03.html`.

### Testing Strategy:
1.  **Manual Inspection:** Open `index.html` and navigate to each `week-X.html` page to visually verify that the content is correctly displayed and the styling is maintained.
2.  **Accordion Functionality:** Test the accordion on each weekly page to ensure that the daily content expands and collapses correctly.
3.  **Content Verification:** Spot-check a few days to ensure that the tasks, snippets, resources, and readings from `course_expanded.md` are accurately reflected in the generated HTML.
4.  **Link Validation:** Check that internal and external links are functional.

### Risks & Mitigation:
*   **Markdown Conversion Accuracy:** Complex Markdown might not convert perfectly.
    *   *Mitigation:* Thorough manual inspection and refinement of the Markdown-to-HTML conversion script.
*   **Accordion Implementation:** The accordion might not work as expected.
    *   *Mitigation:* Start with a simple, well-tested accordion implementation. Test the functionality thoroughly before adding the full course content.
*   **Styling Discrepancies:** New content might not perfectly align with existing CSS.
    *   *Mitigation:* Pay close attention to the HTML structure generated by the script to match the existing patterns.

### Dependencies:
*   `docs/course_expanded.md` (source of content)
*   `src/page_02.html` (HTML boilerplate template)
*   A script for conversion and generation (e.g., Python, Node.js)
